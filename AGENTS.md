# Player photo filename requests

When the user requests a team's player photo filenames, also assign unique,
descriptive Latin-script PNG filenames in the source player records for real
players still using default.png or placeholder.png. Keep existing individual
filenames unchanged unless the user requests a rename. Prefer user-provided
spellings, check filename collisions, and report files that are not yet present
in player-photo/. Assigning a path does not mean an image has been uploaded.
